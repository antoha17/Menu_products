# Тестовый дизайн «Корзины»

Отдельный прототип, не заменяющий основное приложение. Стиль: «Классик» / «Стекло»; режим: Авто / Светлая / Тёмная. Фото блюд не добавлены. Очистка доступна рядом с заголовком; «Вернуть» работает 5 секунд без подтверждения.

## Сборка из корня репозитория

```
python3 tools/prepare-preview.py
python3 tools/build.py preview-source/korzina.html preview
python3 tools/package-preview.py
node preview-source/check-preview.cjs
```

`tools/prepare-preview.py` создаёт отдельный исходник из production `src/korzina.html` и визуального слоя `preview-source/redesign.css`. Основные файлы не перезаписываются. Готовая версия — `preview/`, полный архив — `preview/korzina-test.zip`. Нужны Python с Pillow и Node.js.

## Установка

Открыть https://antoha17.github.io/Menu_products/preview/ в Safari → Поделиться → На экран «Домой». Название: «Корзина тест».

Данные и настройки изолированы префиксом `kz-preview-`. Рецепты можно перенести через сохранение резервной копии в основной версии и восстановление в тестовой. Повторный импорт заменяет данные тестовой копии.

## Проверено

Проверка синтаксиса JS; запуск настоящего кода приложения с моделью DOM в Node: 24 сочетания разделов/стилей/режимов; отсутствие изменений данных при смене темы; порции; очистка и возврат меню и списка; 5 секунд возврата; свои товары; сохранение отдельно от основного хранилища; выбор блюда; создание, редактирование, удаление и возврат рецепта; формирование карточек.

Это не замена проверке на реальном iPhone. Камера, клавиатура iOS, установка на экран «Домой», внешние ИИ и магазины требуют проверки на устройстве. Локальный браузерный предпросмотр в среде сборки не запустился из-за инфраструктуры.

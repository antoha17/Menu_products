# Корзина на неделю

## Как работать с владельцем
- Общение на русском, понятными словами, без лишних терминов.
- Всегда первым предлагать самый удобный для владельца способ, который при этом безопасен. Если удобный способ требует один раз что-то настроить — сказать об этом сразу, а не после обходных вариантов.
- Владелец пользуется приложением на iPhone (iOS 27) как веб-приложением с экрана «Домой».
- Интерфейс минималистичный: без лишних кнопок, без окон подтверждения (удаление — с тостом «Вернуть» и отсчётом 5 секунд), подписи короткие и однозначные.
- Приложение личное: порции в плане ест один человек.

## Устройство
- Исходник: `src/korzina.html` (одна страница, всё внутри). Править только его.
- Сборка: `python3 tools/build.py src/korzina.html .` — пишет в корень репозитория `index.html`, `manifest.webmanifest`, `sw.js` и иконки. Пути относительные: сайт живёт в подпапке.
- Сайт: GitHub Pages из ветки `main`, корень. Адрес: https://antoha17.github.io/Menu_products/ (регистр важен).
- Обновление: собрать, закоммитить, `git push origin main`; через минуту сайт обновится, владельцу достаточно перезапустить приложение.
- Данные пользователя хранятся только в браузере (localStorage) и привязаны к адресу сайта — адрес не менять.
- Коммиты подписывать `antoha17 <antoha17@users.noreply.github.com>`, личную почту не использовать.
